# 05. Core Markdown Rendering

## What to build

Render notes in the Web Vault with first-slice Core Rendering: Markdown, wikilinks with aliases, broken-link styling, tags/frontmatter extraction hooks, common callouts, built-in themes, and attachment/image rendering.

## Acceptance criteria

- [ ] Markdown notes render in preview/read mode by default.
- [ ] Source editing remains available on demand.
- [ ] Wikilinks resolve to notes and support aliases like `[[Note|label]]`.
- [ ] Broken wikilinks render in a distinct color and show a tooltip on hover.
- [ ] Broken wikilinks offer a create-note action.
- [ ] Images and common attachments render or open where feasible.
- [ ] Built-in themes can be selected for the Web Vault reading experience.
- [ ] Community plugin execution and plugin runtime compatibility are not implemented.
